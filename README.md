## 🎯 About This Repository

This repository converts the **CompTIA Network+ N10-009 objectives** into clear, searchable and hands-on learning material. It is designed for learners preparing for the exam and for IT professionals strengthening real-world networking support skills.

> **Learning philosophy:** understand the technology, practise the workflow, document the outcome and troubleshoot methodically.

### ✨ What You Will Find

- 📘 **Domain-by-domain study notes** aligned with N10-009
- 🧠 **Memory aids** for ports, protocols, OSI and networking concepts
- 🧪 **Hands-on labs** for Packet Tracer, Wireshark and command-line tools
- 🛡️ **Network security notes** covering AAA, Zero Trust, NAC and common attacks
- 🛠️ **Troubleshooting workflows** based on symptoms, causes, tests and fixes
- 📋 **Checklists and quick references** for review before the exam

## 🧭 Recommended Learning Path

### 1. 🧱 Build the Foundation

Study the **OSI model, TCP/IP, addressing, ports, protocols and traffic types**.

### 2. 🔀 Implement the Network

Practise **routing, VLANs, trunks, STP, wireless, DHCP and DNS**.

### 3. 📈 Operate and Monitor

Learn **documentation, baselines, SNMP, Syslog, NetFlow, backups and high availability**.

### 4. 🛡️ Secure the Environment

Apply **least privilege, segmentation, secure protocols, NAC, MFA and defence in depth**.

### 5. 🧰 Troubleshoot Systematically

Use the six-step methodology and validate each layer with the correct tool.

## ⚡ Quick Exam Reference

| Topic | Must Remember |
|---|---|
| **OSI** | 7 layers, functions, devices and PDUs |
| **Ports** | DNS 53, DHCP 67/68, HTTP 80, HTTPS 443, SSH 22, RDP 3389 |
| **Routing** | Static vs dynamic, OSPF, BGP, RIP, longest-prefix match |
| **Switching** | VLAN, access/trunk, 802.1Q, STP, LACP, port security |
| **Wireless** | 2.4/5/6 GHz, WPA2/WPA3, 802.1X, interference |
| **Operations** | SNMP, Syslog, NetFlow, SIEM, RPO, RTO, MTTR, MTBF |
| **Security** | CIA, AAA, Zero Trust, ACLs, NAC, common attacks |
| **Troubleshooting** | Symptoms → probable cause → test → fix → verify → document |
