## 🔤 Core Terms

| Term | Definition |
|---|---|
| **ACL** | Ordered permit/deny rules controlling traffic by address, protocol or port |
| **APIPA** | IPv4 link-local addressing in `169.254.0.0/16` when DHCP fails |
| **ARP** | Resolves an IPv4 address to a MAC address on the local segment |
| **BGP** | Path-vector routing protocol used between autonomous systems |
| **Broadcast** | One-to-all traffic within an IPv4 broadcast domain |
| **CIDR** | Prefix-based IP addressing and route aggregation |
| **DHCP** | Automatically assigns IP configuration to clients |
| **DNS** | Resolves names and other records in a distributed hierarchy |
| **FHRP** | Gateway-redundancy family such as HSRP or VRRP |
| **Jitter** | Variation in packet delay |
| **LACP** | Standards-based protocol for link aggregation |
| **Latency** | Time taken for traffic to travel between endpoints |
| **MTU** | Largest packet/frame payload supported without fragmentation at a layer |
| **NAC** | Validates user/device identity and posture before network access |
| **NAT/PAT** | Translates addresses; PAT differentiates sessions with ports |
| **NTP** | Synchronises system clocks |
| **OSPF** | Link-state interior routing protocol using cost |
| **RADIUS** | AAA service commonly used for VPN, Wi-Fi and 802.1X |
| **RPO** | Maximum acceptable data loss measured in time |
| **RTO** | Maximum acceptable service-restoration time |
| **SIEM** | Central platform for log correlation, detection and investigation |
| **SNMP** | Protocol for monitoring and managing network devices |
| **STP** | Prevents Layer 2 loops by creating a loop-free topology |
| **TACACS+** | AAA protocol commonly used for network-device administration |
| **Throughput** | Actual successful data-transfer rate |
| **VLAN** | Logical Layer 2 broadcast-domain segmentation |
| **VPN** | Encrypted or encapsulated tunnel between users, sites or services |
| **Zero Trust** | Security model that continuously verifies each access request |

---

## 🧠 Study Method

For each term, be able to answer:

1. **What is it?**
2. **Which layer or function does it relate to?**
3. **What problem does it solve?**
4. **What symptom appears when it fails?**
5. **Which tool verifies it?**
