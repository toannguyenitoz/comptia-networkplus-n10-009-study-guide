## 📖 Repository Sources

This repository was developed from:

- The **CompTIA Network+ N10-009 exam-domain structure**
- The learning PDF supplied by the repository owner: *CompTIA Network+ N10-009 Full Learning Guide*, curated by Artem Polynko, Version 1.0 (2025)
- Original restructuring, explanations, tables, checklists and hands-on lab ideas created for this GitHub project
- Practical networking knowledge applicable to IT support and systems administration

> ⚠️ The supplied guide states that it is for sharing and **not for resale**. This repository therefore avoids reproducing the complete PDF verbatim and provides independently structured educational notes instead.

---

## ✅ Recommended Authoritative References

When validating technical details, prefer:

- CompTIA’s current Network+ exam objectives
- IETF RFCs for internet protocols
- IEEE standards for Ethernet and wireless technologies
- Microsoft Learn for Windows networking
- Cisco documentation for Cisco-specific protocols and commands
- Wireshark documentation for packet-analysis features

---

## 🧭 How to Use External Material

1. Read the official objective.
2. Explain the concept in your own words.
3. Build or observe it in a lab.
4. Capture evidence with commands or packet analysis.
5. Record the symptom and recovery process.
6. Cite the source when adapting a unique diagram, table or explanation.
